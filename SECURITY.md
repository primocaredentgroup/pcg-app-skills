# Security policy

## Public repository

All repository content is publicly accessible. Do not use issues, discussions, pull requests, commit messages, or code review comments to disclose credentials, personal data, patient data, or confidential company information.

If sensitive material is committed accidentally, stop sharing it, rotate or revoke the affected credential when applicable, and report the incident privately. Removing a file in a later commit does not remove it from Git history.

## Report a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue for a security vulnerability or accidental disclosure.

Include a concise description, affected paths, reproduction steps when safe, and the potential impact. Do not include live credentials or real personal data in the report.
